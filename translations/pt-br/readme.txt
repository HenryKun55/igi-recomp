* DIRECTX 7.0a *

O jogo usa o Microsoft DirectX 7.0a ou superior. Para jogar, você precisa ter drivers compatíveis com o DX7.0a para a sua placa de vídeo e placa de som. Observe que, embora o DirectX 7.0a seja instalado com o jogo, os drivers da sua placa de vídeo e de som não serão atualizados para drivers DirectX 7.0a ou superiores. Você precisa obter os drivers DX7.0a mais recentes com o fabricante da sua placa.

Na Parte II deste documento você encontra uma documentação extensa sobre o DirectX, caso seja relevante para você.

* MEMÓRIA E DESEMPENHO *

Embora o jogo rode bem com 64 MB de RAM, quanto mais memória você tiver, mais suave será a sua experiência.

Independentemente da quantidade de memória, você pode aproveitar ao máximo a memória disponível e aumentar o desempenho geral do motor do jogo fazendo o seguinte:
* Feche todas as janelas abertas.
* Encerre todos os outros programas, inclusive os da barra de tarefas, como o ICQ.
* Desfragmente o seu disco rígido.

Você também pode alterar algumas configurações dentro do jogo para melhorar a taxa de quadros. Use o controle Nível de detalhe na tela Menu Principal / Configurações / Gráficos.

PREPARANDO O DISCO RÍGIDO

Para garantir uma instalação sem problemas, verifique se o disco rígido e o sistema de arquivos estão ajustados para o melhor desempenho. O Windows 95/98/ME/2000 vem com dois utilitários que encontram e corrigem erros e otimizam o desempenho do disco rígido. O primeiro deles se chama ScanDisk. O ScanDisk verifica se há problemas no disco rígido e pode corrigir os que encontrar. Para executá-lo, clique no botão INICIAR da barra de tarefas do Windows 95/98/ME/2000, depois em Programas, Acessórios, Ferramentas do sistema e, por fim, ScanDisk.

Quando o ScanDisk terminar, otimize o desempenho do disco rígido executando o Desfragmentador de disco. Para executá-lo, clique no botão INICIAR da área de trabalho do Windows 95/98/ME/2000, depois em Programas, Acessórios, Ferramentas do sistema e, por fim, Desfragmentador de disco.

INSTALANDO O PROJECT IGI

Instalar o Project IGI é fácil. Basta inserir o CD na unidade de CD-ROM. Após alguns segundos, o Painel de inicialização aparecerá.

Esse programa vai guiá-lo pelo resto do processo com instruções na tela. Se em algum momento for pedido que você reinicie o computador, faça isso.

Caso o Painel de inicialização não apareça quando você inserir o CD:

Dê um clique duplo no ícone MEU COMPUTADOR, depois no ícone do CD-ROM e, por último, no arquivo SETUP.EXE para abrir o Painel de inicialização, OU:

* Clique no botão INICIAR.
* Escolha Executar no menu.
* Digite d:\setup no campo indicado (onde d: é a letra da sua unidade de CD-ROM).
* Clique no botão OK para iniciar o programa de instalação.

Será pedido que você escolha o caminho e a pasta do disco rígido onde deseja instalar o Project IGI. Você pode alterá-los se quiser.

Em algum momento, aparecerá a instalação do Microsoft DirectX 7.0a, caso ele ainda não esteja no seu sistema. Leia as informações na tela antes de escolher uma opção. Você pode optar por instalar ou não nesse momento. Se o instalador detectar uma versão ativa do DirectX 7.0a no sistema, recomendamos que você não reinstale o DirectX. Se o instalador não detectar o DirectX 7.0a, você precisa instalá-lo antes de poder jogar (consulte a próxima seção deste guia antes de continuar).

INICIANDO/CARREGANDO O PROJECT IGI

Quando a instalação terminar e você optar por rodar o jogo, o Painel de inicialização aparecerá na tela. Clique no botão Executar para iniciar o jogo.

Você também pode:
* Clicar no botão Desinstalar para desinstalar o Project IGI.
* Clicar no botão Ver Leia-me para ver o arquivo leia-me.
* Clicar em OK para jogar Project IGI.
* Clicar no botão Sair para fechar o Painel de inicialização.

Se for jogar Project IGI mais tarde, insira o CD na unidade de CD-ROM. Após alguns segundos, o Painel de inicialização deve aparecer na tela por meio da execução automática. Clique então no botão Executar para iniciar o jogo. Há também um botão para Sair.

Caso a execução automática não funcione, você pode clicar no ícone Meu computador e depois no ícone do CD-ROM para abrir o Painel de inicialização

OU

* Clique no botão INICIAR.
* Escolha Programas no menu.
* Arraste o mouse para a direita e clique em Eidos Interactive na lista.
* Arraste o mouse para a direita e clique em Project IGI na lista.
* Clique em Jogar Project IGI no menu que aparecer.

DESINSTALANDO O PROJECT IGI

Se precisar DESINSTALAR o Project IGI, você pode fazer qualquer uma das três coisas a seguir:

Insira o CD do Project IGI na unidade de CD-ROM para ativar a execução automática. Isso abrirá o Painel de inicialização. Clique no botão Desinstalar e depois no botão Sim do painel que aparecer para desinstalar o programa.

OU

* Clique no botão INICIAR.
* Escolha Programas no menu.
* Arraste o mouse para a direita e clique em Eidos Interactive na lista.
* Arraste o mouse para a direita e clique em Project IGI na lista.
* Clique em Remover Project IGI no menu que aparecer e siga as instruções na tela.

OU

Vá ao PAINEL DE CONTROLE e escolha ADICIONAR/REMOVER PROGRAMAS. Clique em Project IGI no painel que aparecer, selecione o botão Adicionar/Remover e siga as instruções na tela.

* PROBLEMAS COM O CD-ROM *

O Project IGI requer no mínimo uma unidade de CD-ROM de velocidade quádrupla com drivers de 32 bits para Windows 95/98/ME/2000.

Recebo a mensagem de erro "xxxxxx.xxx não encontrado" ao instalar ou rodar o Project IGI.

Essa mensagem de erro geralmente aparece quando o computador usa drivers do MS-DOS (16 bits) em vez de drivers do Windows 95 (32 bits) para a unidade de CD-ROM. Você pode verificar facilmente se esse é o problema abrindo o PAINEL DE CONTROLE (clique no ícone "Meu computador" ou no botão INICIAR, depois em "Configurações" e "Painel de controle"). Na janela do Painel de controle, dê um clique duplo no ícone "Sistema" e clique na guia "Desempenho". Você verá um resumo do desempenho do seu computador. Uma das linhas deve dizer "Sistema de arquivos: 32 bits" e a última linha deve dizer "O sistema está configurado para um desempenho ideal". Se aparecer uma mensagem dizendo "A unidade X está usando o modo de compatibilidade com MS-DOS", entre em contato com o fornecedor do seu sistema para obter e instalar drivers de 32 bits para a unidade de CD-ROM.

O jogo inicia AUTOMATICAMENTE várias vezes

Algumas unidades de CD-ROM 24x fazem o Project IGI iniciar automaticamente várias vezes, o que também pode causar perda de controle dentro do jogo. Para resolver esse problema, abra as propriedades do CD-ROM no painel Propriedades do sistema e, nas configurações, desative a Notificação automática de inserção.

* TRAVAMENTOS E CONGELAMENTOS *

* Quando inicio o Project IGI, o cursor do mouse desaparece e o computador trava.
Provavelmente os drivers instalados da sua placa de som não são compatíveis com o DirectX. A única solução é obter um driver compatível com DirectX 7.0a ou superior com o fabricante da placa de som.

* Quando inicio o Project IGI, recebo a seguinte mensagem de erro:
"O aplicativo Project IGI.exe fez referência à memória no endereço xxxx:xxxx, que não pode ser lida."

Provavelmente os drivers instalados da sua placa de vídeo não são compatíveis com o DirectX. A única solução é obter um driver compatível com DirectX 7.0a ou superior com o fabricante da placa de vídeo.

* O instalador sempre para em determinada porcentagem, e não consigo instalar o Project IGI.

Há três causas prováveis:

1) Pode ter acabado o espaço livre no disco rígido. Remova programas que você não usa para liberar espaço para o jogo e reinstale o Project IGI.
2) Os arquivos podem estar sendo copiados para uma área danificada do disco rígido. Nesse caso, execute o ScanDisk e use a opção Completa (veja acima). Depois que o ScanDisk terminar e informar que o disco está sem erros, tente reinstalar.
3) Pode haver sujeira ou marcas de dedos no próprio disco de CD-ROM. Examine o lado de baixo do disco; se houver marcas de dedos ou sujeira, limpe-o com cuidado usando um pano limpo, macio e sem fiapos, passando em linha reta do centro do disco (perto do furo) para a borda.

* O Project IGI fecha e volta para a área de trabalho sem mensagem de erro.

Esse problema pode ter várias causas. Esta é uma lista dos culpados mais comuns por esses travamentos:

1) Verifique se o CD-ROM está limpo (procure arranhões e manchas na superfície de leitura do CD).
2) Verifique se o jogo foi instalado corretamente.
3) Verifique se o DirectX 7.0a ou superior foi instalado corretamente.
4) Verifique se você tem os drivers mais recentes para Windows 95/98/ME/2000 da sua placa de vídeo e se eles são compatíveis com DirectX 7.0a ou superior.
5) Verifique se você tem os drivers mais recentes para Windows 95/98/ME/2000 da sua placa de som e se eles são compatíveis com DirectX 7.0a ou superior.
6) Verifique se a memória virtual está ativada no seu sistema.
7) Execute o ScanDisk.
8) Execute o Desfragmentador de disco.
9) Apague os arquivos temporários antigos (.TMP) da pasta C:\WINDOWS\TEMP ou C:\WIN95\TEMP do disco rígido (pelo Windows Explorer).
10) Verifique se nenhum antivírus (como o Norton AntiVirus) está residente na memória antes de jogar Project IGI.
11) Verifique se nenhum utilitário de gerenciamento de memória de terceiros para Windows 95/98/ME/2000 (como o QEMM 8.0 da QuarterDeck para Windows 95) está residente antes de jogar Project IGI.
12) Verifique se nenhum utilitário de cache de disco de terceiros para Windows 95/98/ME/2000 está residente antes de jogar Project IGI.
13) Verifique se o Norton Crash Protector não está residente antes de jogar Project IGI.
14) Tente desinstalar e reinstalar o jogo.
15)	Tente sair do jogo, reiniciar o computador e entrar no jogo de novo.

Observe que, se o jogo fechar e voltar para a área de trabalho durante uma partida de Project IGI, é recomendável reiniciar o computador antes de jogar de novo. Caso contrário, o DirectDraw ou o DirectSound podem ficar travados, e o jogo não conseguirá usar o seu hardware de som ou de vídeo.

* PROBLEMAS COM A EXECUÇÃO AUTOMÁTICA *

Por que a execução automática não funciona quando insiro o CD do Project IGI na unidade de CD-ROM?

Geralmente é um problema de configuração. Há várias maneiras de ativar a execução automática do Windows 95/98. O método padrão é descrito abaixo:

1)	Abra o PAINEL DE CONTROLE do Windows 95/98/ME/2000 pela área de trabalho clicando no botão INICIAR, depois em CONFIGURAÇÕES e em PAINEL DE CONTROLE.
2)	Dê um clique duplo no ícone SISTEMA, que normalmente fica, em ordem alfabética, perto do fim da janela do Painel de controle, para abrir o painel Propriedades do sistema.
3)	Clique na guia Gerenciador de dispositivos, no alto, e quando o novo painel aparecer, localize a seção CD-ROM e clique no sinal de MAIS (+) na frente dela. (Se houver um sinal de menos na frente, não clique.)
4)	Agora dê um clique duplo na unidade de CD-ROM exibida, e o painel Propriedades do CD-ROM aparecerá.
5)	Clique na guia Configurações, no alto.
6)	Mais ou menos no meio do painel, você verá algumas caixas de seleção na seção Opções. No fim dessa seção, deve haver uma caixa chamada Notificação automática de inserção.
7)	Verifique se a caixa está marcada e clique no botão OK para concluir.

* O que é o DirectX e preciso dele para rodar o Project IGI?

O DirectX é um produto da Microsoft que permite aos desenvolvedores de software e hardware aproveitar o Windows 95/98/ME/2000 ao máximo. Os fabricantes de placas de vídeo e de som precisam desenvolver drivers especiais para as suas placas que trabalhem diretamente com ele. A maioria já fez isso.
O Project IGI usa, em parte, o DirectDraw, o DirectInput e o Direct3D, componentes do DirectX. Se você tiver drivers DirectDraw ou Direct3D instalados no sistema, ou se instalou os drivers do DirectX 7.0a que vêm com o nosso programa e eles forem incompatíveis com a sua placa de vídeo, entre em contato com o fornecedor do seu sistema ou com o fabricante da placa de vídeo para obter os drivers mais recentes. Os fabricantes de placas de vídeo, em especial, costumam atualizar os drivers a cada 2 ou 3 meses. Dependendo da sua placa e de quem a fabrica, há boas chances de haver drivers novos disponíveis. Se você ainda não tem acesso à Internet, recomendamos muito que tenha, pois a maioria das atualizações de drivers é encontrada com mais facilidade nos sites dos diversos fabricantes de hardware.
O Project IGI também usa o DirectSound, além de muitos outros recursos de som novos disponíveis no DirectX 7.0a. Mais uma vez, recomendamos entrar em contato com o fabricante da placa para obter os drivers mais recentes 100% compatíveis com Windows 95/98/ME/2000 e DirectX 7.0a, para garantir o melhor desempenho.

* Como instalo o DirectX?
O DirectX 7.0a da Microsoft vem incluído no instalador do Project IGI. Você terá a opção de instalá-lo por meio de um painel. Clique no botão correspondente para instalar. Se esquecer, pode instalá-lo mais tarde. Veja a seção "Como instalo manualmente os drivers do DirectX?" abaixo para saber como fazer isso.

* Como sei qual versão do DirectX eu tenho? O jogo roda com uma versão mais antiga? E, se eu tiver mesmo uma versão mais antiga do DirectX, onde consigo a mais recente?
O instalador do Project IGI fará o possível para detectar automaticamente qual versão do DirectX está no seu sistema e então pedirá as alterações necessárias. O DirectX 7.0a é a versão mais recente do DirectX. É a versão que acompanha o Project IGI e foi testada a fundo com ele. O Project IGI EXIGE o DirectX 7.0a ou superior para ser jogado. Você não conseguirá jogar se tiver uma versão mais antiga instalada.

* Como instalo manualmente os drivers do DirectX?
Se em algum momento você quiser instalar manualmente os drivers do DirectX 7.0a ou superior da Microsoft, siga os passos abaixo:

1) Abra o Windows Explorer (clique no botão INICIAR, selecione PROGRAMAS e depois WINDOWS EXPLORER, no fim do menu).
2) Coloque o CD do Project IGI na unidade de CD-ROM (se a EXECUÇÃO AUTOMÁTICA aparecer, selecione o botão Explorar CD para voltar ao Windows Explorer e pule o passo 3).
3) Abra a unidade de CD-ROM (geralmente D:\) e localize a pasta DXSetup.
4) Localize o arquivo DXSETUP.EXE e dê um clique duplo nele para iniciar a instalação manual do DirectX.
5) Um painel chamado Instalação do DirectX aparecerá no canto superior esquerdo da tela (pode levar alguns segundos).
6) Clique no botão Reinstalar DirectX. A instalação começará. Se aparecer a seguinte mensagem:
"A instalação detectou drivers de vídeo que não foram testados com o DirectX. Para obter o melhor desempenho nos jogos, a instalação pode substituir os seus drivers atuais. Deseja que a instalação substitua os drivers?"
selecione o botão NÃO, para não sobrescrever nem correr o risco de danificar os drivers de vídeo originais. (Observe, porém, que se os problemas continuarem após a instalação, você pode repetir os passos 1 a 6 e selecionar SIM nessa opção. Lembre-se: você pode restaurar os drivers originais depois, se algo der errado.)
7) Por fim, será pedido que você reinicie o computador. Selecione o botão SIM para reiniciar e carregar os novos drivers.

* Socorro! O Project IGI deixou o meu sistema instável, e desconfio que o culpado é o DirectX. Como restauro os drivers originais?
O DirectX se tornou o novo padrão no desenvolvimento de aplicativos para Windows 95/98/ME/2000. Quase todo software de alto desempenho será feito em torno dessa tecnologia, por isso normalmente não recomendamos que os clientes tentem alterar a instalação dele no sistema. Infelizmente, há alguns sistemas e dispositivos de hardware que ainda não funcionam com o DirectX, e instalá-lo nesses sistemas pode causar problemas de drivers. NÃO É POSSÍVEL REMOVER O DIRECTX DO SISTEMA, mas você pode restaurar os drivers de áudio e vídeo originais que a instalação do DirectX substituiu.

Se você tem o DirectX 7.0a ou superior instalado, pelo Project IGI ou antes dele, deve conseguir restaurar os drivers originais na seção ADICIONAR/REMOVER PROGRAMAS do PAINEL DE CONTROLE do Windows 95.

Ao entrar no PAINEL DE CONTROLE do Windows 95/98/ME/2000 e clicar no ícone ADICIONAR/REMOVER PROGRAMAS, você verá no painel Propriedades de Adicionar/remover programas uma lista de todos os programas registrados no Windows 95/98/ME/2000.

Se aparecer o item "DirectX Drivers", dê um clique duplo nele para abrir o painel de instalação do DirectX. No fim desse painel deve haver um botão chamado Restaurar drivers de vídeo. Clicar nesse botão deve restaurar os drivers de vídeo originais. Depois, clique no outro botão, chamado Restaurar drivers de áudio. Embora o DirectX continue no sistema, a restauração dos drivers antigos pode permitir que você rode o programa. Se não permitir, considere entrar em contato com o fornecedor do seu sistema para obter drivers 100% compatíveis com DirectX para as suas placas de vídeo e/ou de som OU visite o site do fabricante do hardware.

* Rodar sem DirectX?

Se o DirectX não estiver instalado no seu computador, você NÃO conseguirá rodar o Project IGI.
